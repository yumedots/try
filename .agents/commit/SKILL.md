# Commit messages

## Permission required — never commit unprompted

Never run `git commit` unless the user has explicitly asked in this conversation. Finishing a task, fixing a bug, or passing tests is not permission. The user reviews and tests changes before committing. If unsure, ask instead of committing.

## Message format

Single short lowercase line. No body, no description, no author/co-author footers.

If the repo enforces a format with a commit-msg hook, follow it.
